Política de Privacidade

Finanças AI Lab · atualizada em 20 de novembro de 2026

O Finanças AI Lab é um assistente financeiro pessoal, de uso privado de uma família, que funciona por mensagens no Telegram. Esta página explica quais dados ele usa e o que é feito com eles.

Quem pode usar

Só as pessoas autorizadas pela administradora do assistente. Quem não está autorizado não consegue registrar nem consultar nada.

Quais dados são coletados

  • O identificador da conversa no Telegram (chat_id), usado para separar os dados de cada pessoa.
  • As mensagens enviadas ao assistente e os lançamentos que vêm delas: data, descrição, valor, categoria, forma de pagamento e parcelas.
  • As metas de economia criadas e os valores guardados nelas.

Onde os dados ficam

Os lançamentos e as metas ficam numa planilha do Google Sheets da administradora. O assistente acessa essa planilha pela API do Google, com autorização da própria administradora, e só lê e escreve nessa planilha.

Como os dados são usados

  • Para registrar gastos e receitas, responder consultas, calcular indicadores do mês e acompanhar metas.
  • O texto das mensagens é enviado a um serviço de inteligência artificial (Groq) apenas para entender o pedido e escrever o diagnóstico do mês.

O que não é feito

  • Os dados não são vendidos nem compartilhados com terceiros para publicidade ou qualquer outro fim.
  • Cada pessoa vê, pelo assistente, só os próprios dados.

Com transparência: quem administra a planilha consegue ver todos os lançamentos guardados nela.

Seus direitos

Você pode pedir a qualquer momento para ver, corrigir ou apagar os seus dados, falando com a administradora do assistente. O endereço de contato aparece na tela de autorização do Google.

Uso dos dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
